## Problem

`expand_concept()` used `thinkingBudget=2048` for the Gemini 2.5 Flash primary path. A second substantive-relevance failure surfaced at this budget: for "gladue principle", Gemini proposed "Fundy Settlement v Canada, 2012 SCC 14" — a real SCC tax case with zero connection to Indigenous sentencing / s.718.2(e). This followed the earlier R v Zora incident (already prompt-blocked by name). The underlying pattern of surfacing real-but-topically-unrelated cases with numerically/temporally adjacent citations was not resolved by that point-fix.

## Fix

No prompt content, verification logic, fallback path, or any other function was touched.
