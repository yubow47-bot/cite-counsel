# Review Request: Add /favicon.ico for Google favicon crawler

_Generated by Claude Code._

## Problem

`https://citecounsel.com/favicon.ico` returns a Next.js 404 page. Browsers
read `<link>` metadata tags and work fine with `/icon.svg` — but Google's
favicon crawler requests the literal `/favicon.ico` path directly, without
reading HTML. That path was serving nothing, so Google shows a stale
cached icon.

## Fix

Generated `frontend/app/favicon.ico` from the existing
`frontend/public/icon-32x32.png` using Python Pillow:

```python
Image.open("frontend/public/icon-32x32.png").save(
    "frontend/app/favicon.ico", format="ICO", sizes=[(32, 32)]
)
```

Next.js App Router automatically serves `app/favicon.ico` at the site root
`/favicon.ico` path. No changes to `app/layout.tsx` — the existing
`<link>`-based icon declarations remain.
