# Review Request: CanLII Legislation Fallback — Citation-Suffix Stripping

_Generated by Claude Code._

---

## Bug

When `classify_and_normalize()` expands a statute abbreviation into a full
citation (e.g. `"Family Law Act"` → `"Family Law Act, RSO 1990, c F.3"`),
the CanLII fallback branch in `search_citation()` fails because `cit_match`'s
regex does not recognize provincial revised-statute prefixes like `RSO`.
The fully-expanded string is passed to CanLII title matching verbatim,
producing a miss even though the statute exists in CanLII's database.

This is nondeterministic: the same query succeeds when the LLM happens NOT
to expand the abbreviation, and fails when it does.

## Fix

Added a narrow helper `_strip_citation_suffix_for_title_match()` that
detects and strips a trailing `, ABBR YYYY` pattern (e.g. `, RSO 1990`),
optionally followed by a `, c …` chapter clause, anchored to the end of
the string.  The remaining clean title ("Family Law Act") then correctly
hits the exact-match path against CanLII's legislations list.

### Regex tightening (round 2)

After audit feedback the regex was tightened from:

```python
# Original: unanchored, first-match anywhere
_CITATION_SUFFIX_RE = re.compile(r',\s*[A-Z]{2,6}\s+\d{4}')
```

to:

```python
# Tightened: end-anchored, optional chapter clause, case-insensitive
_CITATION_SUFFIX_RE = re.compile(
    r',\s*[A-Z]{2,6}\s+\d{4}(?:,\s*c\s+[^,]+)?\s*$',
    re.IGNORECASE,
)
```

Three changes:
1. **`\s*$` end anchor** — the pattern must match at end-of-string,
   preventing a mid-title `, ABC 1990` from being stripped.
2. **Optional `(?:,\s*c\s+[^,]+)?` chapter clause** — allows the full
   canonical suffix `, RSO 1990, c F.3` to be matched and removed in one
   pass, rather than depending on the pinpoint-stripping step.
3. **`re.IGNORECASE`** — robust to non-canonical casing (e.g. `"Rso"`,
   `"rso"`) even though the classifier is expected to produce uppercase
   abbreviations.

**Scope**: Only the `title_for_match` variable used for CanLII title
matching.  `cit_match`'s regex and A2AJ routing are **not** modified.

## Exact Reproduction Test

The following test (`test_rso_expanded_exact_match`) reproduces the reported
bug and verifies the fix:

```python
FLA_RECORD = {
    "databaseId": "ons", "legislationId": "so-fla",
    "title": "Family Law Act",
    "citation": "RSO 1990, c F.3", "type": "STATUTE",
}

CLASSIFICATION_FLA_EXPANDED = {
    "type": "legislation",
    "normalized": "Family Law Act, RSO 1990, c F.3",
    "original": "family law act ontario",
}

def test_rso_expanded_exact_match():
    mock_canlii = MagicMock(return_value={"legislations": [FLA_RECORD]})
    mock_infer = MagicMock(side_effect=Exception("LLM should not be called"))

    with patch("local_tools.citation_search._infer_jurisdiction_canlii", mock_infer), \
         patch("local_tools.canlii_api.browse_legislation_in_database", mock_canlii):
        result = search_citation("family law act ontario", CLASSIFICATION_FLA_EXPANDED)

    assert result[0]["verified"] is True
    assert result[0]["_match_path"] == "exact"
```

**Before the fix**: `verified=False`, `_match_path="no_exact_match"`.

**After the fix**: `verified=True`, `_match_path="exact"`.

## Embedded-Pattern Negative Test

Proves the end anchor (`$`) prevents mid-title stripping:

```python
def test_strip_suffix_embedded_not_trailing():
    ### Embedded ', ABC 1990' substring NOT at end of string — must remain unchanged.
    result = _strip_citation_suffix_for_title_match(
        "Some Act, ABC 1990 Historical Review Act"
    )
    assert result == "Some Act, ABC 1990 Historical Review Act"
```
