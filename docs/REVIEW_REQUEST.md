# Review Request: CanLII Legislation Fallback — Citation-Suffix Stripping & UX

_Generated by Claude Code._

---

## Bug (Round 1)

When `classify_and_normalize()` expands a statute abbreviation into a full
citation (e.g. `"Family Law Act"` → `"Family Law Act, RSO 1990, c F.3"`),
the CanLII fallback branch in `search_citation()` fails because `cit_match`'s
regex does not recognize provincial revised-statute prefixes like `RSO`.
The fully-expanded string is passed to CanLII title matching verbatim,
producing a miss even though the statute exists in CanLII's database.

This is nondeterministic: the same query succeeds when the LLM happens NOT
to expand the abbreviation, and fails when it does.

## UX Improvement (Round 2)

When `_prescan_jurisdiction()` and `_infer_jurisdiction_canlii()` both fail
to resolve a jurisdiction (signalled by `_match_path == "jur_none"`), the user
previously saw the same generic "couldn't verify" message as every other
unverified legislation query. Now they get a specific hint telling them to
include a province or territory in their search.

**Scope**: Only the `disabled_message` passed to `_scaffold_response()` for
the `jur_none` failure mode. No CanLII query logic, `_prescan_jurisdiction`,
or `_infer_jurisdiction_canlii` are touched.
