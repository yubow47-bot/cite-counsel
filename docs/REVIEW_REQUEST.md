## Problem

`expand_concept()` surfaced two real-but-substantively-unrelated cases for "gladue principle", both following a specific pattern: **citation-number/year proximity to a correct core case**.

| Incident | Budget | Appeared alongside | Pattern |
|----------|--------|-------------------|---------|
| Fundy Settlement v Canada (2012 SCC 14) | 2048 | R v Ipeelee (2012 SCC 13) | Same year, sequential SCC number |
| Barer v Knight Brothers LLC (2019 SCC 13) | 4096 | R v Ipeelee (2012 SCC 13) | Same SCC sequence number, different year |

Both are real SCC cases with zero substantive connection to Gladue/Indigenous sentencing:
- **Fundy Settlement**: trust tax-residency case
- **Barer**: international arbitral-award enforcement case

This is a distinct, nameable failure mode: the model associates candidates via citation-number/year proximity to a correct anchor case, rather than via substantive legal content.

## Fix

Added two new prompt rules (prompt-content-only — no other code changed):

1. **Citation-number proximity prohibition**: Explicitly instructs the model NOT to select candidates based on SCC sequence-number similarity, year proximity, or docket-number adjacency. Only substantive legal subject-matter connection is valid.

2. **Named negative examples**: Added Fundy Settlement v Canada and Barer v Knight Brothers LLC as excluded examples, alongside the existing R v Zora, all flagged as "real SCC cases with zero substantive connection" selected via citation-number proximity, not subject matter.

Also added a general catch-all rule: "if you cannot articulate which substantive legal doctrine the candidate is cited for, exclude it."

## Open Items

1. **R v Anderson (2014 SCC 41) appears in every run** — This is a substantively correct Gladue-related case (Indigenous sentencing in the Ontario Court of Appeal context), not a citation-proximate intrusion. Its consistent appearance across all 5 runs suggests stable, correct model behavior.

2. **A2AJ transient timeouts** — Runs 1 and 5 showed A2AJ connectivity issues causing some candidates to return unverified. This is a network-level issue, not related to the prompt change.

3. **Citation-number proximity is a prompt-level guard** — The new rules are instructions to the LLM, not deterministic constraints. A sufficiently motivated model could still produce a citation-proximate case. The exclude-list approach (naming specific cases) is brittle; if a third proximity incident occurs, consider structural changes (e.g., post-processing to filter candidates whose citation is numerically adjacent to another candidate's).
